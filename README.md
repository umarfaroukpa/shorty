Custom Domain and Custom URL Logic:

If a customDomain is provided, the short URL is constructed using this domain.
If a customUrl is provided, it is used as the shortCode (the unique identifier in the shortened URL).

Example Flow for User Creation:
User Steps:
    User signs up.
    They add their custom domain (e.g., mycompany.com) in the account settings.
    User creates a new short URL by providing the original URL and their custom domain and/or custom URL (e.g., https://mycompany.com/sale).
    The system validates the custom URL and checks the DNS records for the custom domain.
    Once verified, the custom short URL is saved and ready for use.
